#  Yoga Video Dataset

##  About the Dataset

The Yoga Video Dataset was created and curated by our project groups as part of our academic project.

This dataset contains categorized yoga pose videos collected and structured for training a model which suggests improvements in yoga posture in real-time. 
--------------------------------------------------------------------------------------------------------------
## Dataset Details

- Multiple yoga pose video samples
- Organized class-wise folders
- Suitable for pose classification and action recognition
- The Dataset contains videos with diverse backgrounds, Multiple lighting conditions, Different clothing styles and Multiple body types
--------------------------------------------------------------------------------------------------------------
## Dataset Structure

The dataset used for this project is organized as follows:

Final_project3_dataset/
